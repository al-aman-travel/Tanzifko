# موقع شركة تنظيفكو المحلية

موقع تأجير حاويات الأنقاض والمخلفات في الكويت. مبني بـ Astro، ولوحة التحكم Sveltia CMS، والاستضافة مجانية على GitHub Pages.

- العربية في الجذر (`/`) والإنجليزية تحت `/en/`، ولكل صفحة نسخة مقابلة مربوطة بـ hreflang.
- الطلب عبر واتساب مباشرة: نموذج الطلب يجهّز رسالة واتساب ولا يحفظ أي بيانات.
- لوحة التحكم: `/admin/`، وتدخلها بحساب GitHub له صلاحية على المستودع.

## الاسم
الاسم دائمًا «تنظيفكو المحلية» أو «شركة تنظيفكو المحلية»، ولا تُكتب «تنظيفكو» وحدها لوجود شركة أخرى بهذا الاسم.
بالإنجليزية: Tanzeefko Local.

## ربط الدومين
1. اكتب الدومين في `site.config.mjs` (السطر `DOMAIN`).
2. في إعدادات المستودع ← Pages: ضع الدومين نفسه في Custom domain وفعّل Enforce HTTPS.
3. وجّه الدومين من شركة التسجيل إلى GitHub Pages (سجلات A الأربعة وسجل CNAME لـ www).

قبل ربط الدومين يعمل الموقع للمعاينة على `https://al-aman-travel.github.io/Tanzifko/`، وكل صفحاته noindex حتى لا يفهرس جوجل رابطًا مؤقتًا.

## التطوير
```
npm install
npm run dev
npm run build
```
